This repository serves as my hands-on playground and cheat sheet for mastering Bash shell scripting. It contains a comprehensive myscript.sh file that covers essential fundamentals including variables, user input handling, multiple conditional loops, function parameters, and automated file-system operations.
Every single step of this project—from initializing the files and writing the script logic, to provisioning the cloud repository and pushing the code—was executed 100% through the Linux CLI and terminal environments. No graphical interfaces or web browsers were used to build, manage, or deploy these files.
This environment acts as a living reference document for real-world automated tasks. Moving forward, I plan to expand this toolkit with more advanced shell configurations and operational automation scripts.
